# 设计规范

> 本文件是界面视觉与交互的唯一真源。**改任何 UI 前必读**，改完必须回写本文件。
> 设计目标：**简洁、直观**；主色调**淡粉色**。

---

## 1. 设计原则

1. **一眼看到最新**：最新复制的内容永远在最上方。
2. **操作少而准**：每张卡片只有必要的四个操作，悬停才出现，不喧宾夺主。
3. **状态可辨**：置顶、暂停、已复制、失败，都要有明确且克制的视觉反馈。
4. **低刺激**：淡粉为点缀，不铺满；文字对比度足，长时间看不累。
5. **无惊吓**：破坏性操作要么可撤销，要么二次确认。

## 2. 设计令牌（Design Tokens）

所有颜色、圆角、间距、字号**只能**通过 CSS 自定义属性使用，禁止在组件里写魔法值。

```css
:root {
  /* 主色（淡粉色系） */
  --color-bg:            #FFF5F7;  /* 窗口背景 */
  --color-surface:       #FFFFFF;  /* 卡片背景 */
  --color-surface-alt:   #FDEEF2;  /* 次级面板/悬停底色 */
  --color-primary:       #F7A8BC;  /* 主色：主按钮、选中态、置顶竖条 */
  --color-primary-hover: #F291A9;  /* 主色悬停 */
  --color-primary-soft:  #FDE3EA;  /* 主色浅底：标签、提示条 */
  --color-border:        #F3DCE3;  /* 分隔线与描边 */

  /* 文字 */
  --color-text:          #4A3F44;  /* 主文字 */
  --color-text-muted:    #9B8C93;  /* 次要文字：时间、元信息 */
  --color-text-invert:   #FFFFFF;  /* 主色按钮上的文字 */

  /* 语义色（克制使用） */
  --color-danger:        #E5737F;  /* 删除 */
  --color-warn-bg:       #FFF4E0;  /* 提示条背景 */
  --color-warn-text:     #8A6A2F;  /* 提示条文字 */

  /* 圆角 */
  --radius-card:  10px;
  --radius-input: 8px;
  --radius-pill:  999px;

  /* 间距（4px 基准） */
  --space-1: 4px;  --space-2: 8px;  --space-3: 12px;
  --space-4: 16px; --space-5: 24px; --space-6: 32px;

  /* 字号 */
  --font-xs: 11px;  /* 时间、元信息 */
  --font-sm: 12px;  /* 次要说明 */
  --font-md: 13px;  /* 正文预览 */
  --font-lg: 15px;  /* 标题 */
  --font-xl: 18px;  /* 主标题 */

  /* 其他 */
  --shadow-card: 0 1px 3px rgba(74, 63, 68, 0.06);
  --shadow-pop:  0 4px 16px rgba(74, 63, 68, 0.12);
  --duration-fast: 120ms;
  --duration-base: 180ms;
}
```

**用色比例**：背景与卡片（近白）约 85%，淡粉点缀（主按钮、置顶条、选中态）约 15%。**不要**把粉色用于大面积背景填充。

## 3. 字体与排版

- 字体族：`"Microsoft YaHei UI", "Segoe UI", system-ui, sans-serif`。
- 数字与时间：可用 `"Segoe UI", system-ui` 保证数字等宽观感。
- 行高：正文 1.5；标题 1.3。
- 文本预览：**最多 2 行**，超出以省略号截断（`-webkit-line-clamp: 2`）。
- 中英文混排不加额外空格；不整段加粗。

## 4. 布局

```
┌──────────────────────────────────────────────┐
│  🔍 搜索历史…              [全部|文字|图片]  ⚙️ │  ← 顶栏（吸顶）
├──────────────────────────────────────────────┤
│  今天                                         │  ← 日期分组头
│  ┌────────────────────────────────────────┐  │
│  │▌ [缩略图]  14:32                        │  │  ← 卡片（▌为置顶竖条）
│  │           这是一段被复制的文字预览…      │  │
│  │                          📌  📋  ⤵  🗑  │  │  ← 悬停显示操作
│  └────────────────────────────────────────┘  │
│  ┌────────────────────────────────────────┐  │
│  │  [图片]    14:15   1920×1080 · 278 KB   │  │
│  └────────────────────────────────────────┘  │
│  昨天                                         │
│  ...                                          │
└──────────────────────────────────────────────┘
```

| 区域 | 尺寸与规则 |
|---|---|
| 窗口默认 | 420 × 640；最小 360 × 480；可调整大小；记忆位置 |
| 顶栏高度 | 56px，背景 `--color-surface`，底部 1px `--color-border` |
| 搜索框 | 高 34px，圆角 `--radius-input`，聚焦时描边 `--color-primary` |
| 筛选分段 | 三段胶囊，选中段背景 `--color-primary`、文字 `--color-text-invert` |
| 卡片 | 内边距 `--space-3`，圆角 `--radius-card`，`--shadow-card`，卡片间距 `--space-2` |
| 缩略图 | 56 × 56，圆角 6px，图片按 `object-fit: cover` |
| 日期分组头 | 高 28px，`--font-xs`，`--color-text-muted`，吸顶 |

## 5. 卡片状态

| 状态 | 视觉 |
|---|---|
| 默认 | 白底、浅阴影 |
| 悬停 | 背景转 `--color-surface-alt`，操作按钮淡入（`--duration-fast`） |
| 置顶 | 左侧 3px `--color-primary` 竖条，右上角**实心**图钉 |
| 选中（键盘导航） | 1px `--color-primary` 描边 + `--color-primary-soft` 底 |
| 已复制成功 | 卡片短暂显示「已复制」轻提示（1.2s 后消失） |
| 已删除（待撤销） | 显示带「撤销」按钮的提示条，5s 后消失 |
| 内容截断 | 预览末尾标注「内容过长，已截断」 |
| 图片丢失 | 占位图 + 「图片已丢失」 |
| 全文丢失 | 显示预览 + 「全文已丢失」 |

## 6. 操作与图标

| 操作 | 图标 | 悬停提示 | 行为 |
|---|---|---|---|
| 复制 | 📋 | 复制到剪贴板 | 写回剪贴板，不切换窗口 |
| 粘贴 | ⤵ | 复制并粘贴到当前窗口 | 写回剪贴板 + 自动 Ctrl+V |
| 置顶/取消 | 📌 | 置顶 / 取消置顶 | 切换 `pinned` |
| 删除 | 🗑 | 删除 | 立即删除 + 提供撤销 |

- 图标**必须**带 `title` 或 `aria-label`（中文），不依赖图标自明。
- 若 `pasteMode === 'copyOnly'`：卡片主按钮顺序与文案切换为以「复制」为主，「粘贴」降为次要，并在按钮 tooltip 说明当前设置。
- 「清空历史」放在设置面板内，需二次确认，且明确文案：**「将删除所有未置顶记录，置顶记录会保留」**。

## 7. 交互与键盘

| 按键 | 行为 |
|---|---|
| `Esc` | 关闭窗口（隐藏到托盘，不退出） |
| `↑` / `↓` | 上下切换选中卡片 |
| `Enter` | 对选中卡片执行默认粘贴动作（跟随 `pasteMode`） |
| `Ctrl+F` | 聚焦搜索框 |
| `Ctrl+C`（列表聚焦时） | 复制选中卡片（不劫持输入框内的复制） |

- 搜索为**即时过滤**，无需回车；空查询显示全部。
- 删除：默认 5 秒内可撤销；超时后正式生效。
- 加载中：列表区显示轻量骨架块，不使用转圈遮罩。
- 空状态：插画/图标 + 「还没有记录，复制点东西试试」，并提示托盘仍在后台运行。

## 8. 反馈与提示

- 轻提示（Toast）：顶部居中，圆角 `--radius-pill`，成功用 `--color-primary-soft`，失败用 `--color-warn-bg` + `--color-warn-text`。
- 失败必须说清**原因与下一步**，例如：**「当前窗口以管理员权限运行，无法自动粘贴，请按 Ctrl+V」**，不得只提示「失败」。
- 托盘暂停时，图标变灰，窗口内顶栏显示「记录已暂停」提示条。

## 9. 无障碍与适配

- 全界面键盘可达；焦点态必须可见（`--color-primary` 描边），不给 `outline: none` 却不补替代样式。
- 文字与背景对比度：主文字 ≥ 7:1；次要文字 ≥ 4.5:1（`#9B8C93` 仅用于非关键元信息）。
- 尊重 `prefers-reduced-motion: reduce`：关闭淡入与位移过渡。
- 支持 Windows 缩放 100%–200%，布局在最小宽度 360px 下不重叠、不横向滚动。
- 触摸/高 DPI 下点击目标不小于 28 × 28px。

## 10. 禁止事项

- ❌ 组件内硬编码颜色/圆角/间距（必须用令牌）。
- ❌ 大面积粉色填充、渐变滥用、多色彩虹式语义色。
- ❌ 无确认的破坏性操作（清空历史）。
- ❌ 只用图标无文字提示的可点击元素。
- ❌ 弹窗套弹窗；设置面板为单个侧滑/弹层面板即可。
