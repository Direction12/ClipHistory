## 1. 产品目标

做一个常驻 Windows 的本地剪贴板历史工具：后台自动记录用户最近复制的**文字和图片**，在淡粉色简洁界面里按**时间降序**展示卡片，支持**置顶、删除、搜索、类型筛选**，可按 **1 / 3 / 5 天（含自定义）** 自动清理过期内容（**置顶内容永久保留**），并支持一键**复制或自动粘贴**回当前窗口。

## 2. 成功标准

| 编号 | 标准 |
|---|---|
| SC-1 | 在任意程序 Ctrl+C 复制文字或截图后，800ms 内出现在列表最上方 |
| SC-2 | 托盘常驻：关窗口不退出、不中断记录；托盘菜单可开窗、暂停、清空、退出 |
| SC-3 | 按 1/3/5 天设置生效：到期且未置顶的条目自动删除，置顶条目永不自动删除 |
| SC-4 | 搜索框关键词即时过滤；类型筛选（全部/文字/图片）与搜索可叠加 |
| SC-5 | 「复制」写回剪贴板；「粘贴」写回剪贴板并模拟 Ctrl+V 落到切换后的前台窗口 |
| SC-6 | 断网可用、不上传任何数据、无任何运行时网络请求 |
| SC-7 | 可打包为可双击运行的 Windows 安装包 / 免安装 exe |

## 3. 范围

### 3.1 v1.0 范围内（本版必做）

- 文字与图片两种内容的自动采集
- 托盘常驻 + 关窗隐藏
- 时间降序卡片列表、置顶、删除、搜索、类型筛选
- 存储期限全局设置（1/3/5 天 + 自定义）
- 复制到剪贴板 + 自动粘贴（可设置为仅复制）
- 纯本地存储

### 3.2 v1.0 范围外（明确不做，后续备选）

| 项目 | 原因 |
|---|---|
| 全局快捷键唤起 | 用户未选入 v1 |
| 开机自启动 | 用户未选入 v1 |
| 导出 / 备份为文件 | 用户未选入 v1 |
| 多设备同步、云备份 | 与「纯本地、不上传」原则冲突 |
| 富文本 / HTML 格式、文件路径列表 | 只做文字与图片两种类型 |
| 每条内容单独设置期限 | 采用全局期限 + 置顶豁免，降低复杂度 |
| 图片 OCR、文本搜索命中图片 | 超出 v1 目标 |

## 4. 功能需求（FR）

| 编号 | 需求 | 说明 | 验收要点 |
|---|---|---|---|
| FR-01 | 后台自动采集 | 轮询剪贴板，每 800ms 一次，记录用户新复制的内容 | 复制后出现在列表顶部 |
| FR-02 | 文字采集 | 记录纯文本，去 BOM，保留换行与空白结构 | 多行文本可完整取回 |
| FR-03 | 图片采集 | 记录位图，统一转 PNG 落地并记录宽高与字节数 | 截图后出现图片卡片 |
| FR-04 | 内容去重 | 同内容在去重窗口（默认 5s）内只算一次；超出窗口再次复制则刷新时间戳、不新增重复条目 | 反复复制同一段文字不刷屏 |
| FR-05 | 忽略规则 | 空串、纯空白、仅换行不入库；超长文本（>10 万字符）入库但截断并标注 | 清空剪贴板不产生垃圾条目 |
| FR-06 | 防自触发 | 软件自身写回剪贴板的内容不得被重新记录 | 点击「复制」后列表不新增条目 |
| FR-07 | 托盘常驻 | 托盘图标常驻；菜单含 打开 / 暂停记录 / 清空历史（保留置顶）/ 设置 / 退出 | 关窗后进程存续、记录继续 |
| FR-08 | 时间降序卡片列表 | 按时间降序排列；带日期分组头（今天 / 昨天 / 具体日期） | 最新内容在最上方 |
| FR-09 | 卡片操作 | 置顶 / 取消置顶、删除（可撤销）、复制、粘贴 | 四个操作均生效 |
| FR-10 | 搜索 | 对文字内容实时关键词过滤，大小写不敏感，支持中文 | 输入即过滤 |
| FR-11 | 类型筛选 | 全部 / 文字 / 图片 分段筛选，可与搜索叠加 | 叠加结果正确 |
| FR-12 | 存储期限 | 全局设置 1/3/5 天预设或自定义（1–365 天）；按最近复制时间判定；置顶条目永久保留 | 未置顶过期消失、置顶保留 |
| FR-13 | 粘贴行为可配置 | 设置项 `pasteMode`：自动粘贴 / 仅复制，决定卡片主按钮默认行为 | 切换后主按钮行为随之改变 |
| FR-14 | 生命周期 | 单实例锁；窗口位置与尺寸记忆并在屏幕可见范围内校正 | 二次启动唤起已有窗口 |
| FR-15 | 清空历史 | 保留置顶条目，执行前二次确认 | 清空后置顶仍在 |

## 5. 非功能需求（NFR）

| 编号 | 需求 |
|---|---|
| NFR-01 | 纯本地：无运行期网络请求、无遥测、无自动更新检查 |
| NFR-02 | 数据目录位于系统用户数据目录，不写入程序安装目录与项目仓库 |
| NFR-03 | 渲染层不得直接访问 Node/文件系统，全部经 preload 白名单 IPC |
| NFR-04 | 启动到窗口可用 < 2s；1 万条历史下列表滚动流畅 |
| NFR-05 | 索引单行损坏不得导致整库不可用 |
| NFR-06 | 界面文案全中文 |
| NFR-07 | 运行时依赖尽量少，仅 electron 一个 |

## 6. 界面需求（摘要）

详细规范见 [`设计规范.md`](设计规范.md)。

- 配色：淡粉色系。主背景 `#FFF5F7`、卡片 `#FFFFFF`、主色 `#F7A8BC`、主文字 `#4A3F44`、次要文字 `#9B8C93`。
- 顶部：搜索框 + 「全部/文字/图片」分段筛选 + 设置按钮。
- 卡片：缩略图或文本图标、时间、内容预览；悬停出现操作按钮；置顶卡片左侧粉色竖条 + 图钉标记。
- 交互：`Esc` 关闭窗口（回托盘）、`↑/↓` 切换选中卡片、`Enter` 执行默认粘贴动作、`Ctrl+F` 聚焦搜索框。

## 7. 已知限制（必须在文档与界面中明示）

| 编号 | 限制 | 处理方式 |
|---|---|---|
| LIM-01 | 以管理员权限运行的窗口（任务管理器、UAC 提权程序）无法接收模拟按键，自动粘贴无效 | 明确提示用户手动 Ctrl+V，不静默失败 |
| LIM-02 | Windows 上无可靠的原生剪贴板变更事件，只能轮询 | 采用 800ms 轮询，开销可忽略 |
| LIM-03 | 剪贴板被其他程序短暂占用时写入可能失败 | 自动重试一次，仍失败则提示 |
| LIM-04 | 图片无独立格式信息，统一按 PNG 落地 | 可能比原始格式占用略大 |

## 8. 验收方式

- 每个阶段收尾按 [`文档维护规范.md`](文档维护规范.md) 更新开发日志。
