# 测试与验收标准

> 本文件是测试范围与验收口径的唯一真源。**每个阶段收尾时按本文件执行。**

---

## 1. 测试原则

1. **测纯逻辑，不测像素**：存储、去重、保留策略、搜索筛选、设置容错用 `node:test` 覆盖，不引入 Electron 运行期做 UI 断言。
2. **测试不需要 GUI**：`npm test` 必须能在无窗口环境下跑通，且不依赖用户真实剪贴板。
3. **时钟可注入**：涉及时间的逻辑（去重窗口、保留期限）必须接受注入的时间源，测试用固定时间，**不使用 `setTimeout` 等真实等待**。
4. **数据目录可覆盖**：测试使用临时目录，**绝不触碰** `%APPDATA%\ClipHistory` 真实数据。
5. **失败要能定位**：断言消息写明输入与期望，便于不看代码即知问题。

## 2. 测试范围（必须覆盖）

| 编号 | 模块 | 覆盖点 |
|---|---|---|
| T-01 | store 索引 | 追加后读取一致；同 `id` 后写覆盖前写 |

| T-03 | store 压缩 | 压缩后条目数与内容与压缩前一致；冗余行被清除 |

| T-06 | 哈希 | 文本按规范化字节计算（`\r\n` → `\n`、去 BOM）；图片按其 PNG 字节计算 |

| T-08 | 保留策略 | 1/3/5 天边界：恰好到期、刚过期、未过期，判定正确 |

| T-10 | 孤儿回收 | 不再被引用的图片被删除；仍被引用（含多条目共享）的图片保留 |

| T-16 | 设置持久化 | 写入后可回读；原子写入不产生半截文件 |

## 3. 测试命名与结构

- 位置：`test/<模块>.test.ts`，与 `src/` 下模块一一对应。
- 命名：`describe('<模块> — <行为>')`，用例名用中文描述期望，例如：

```ts
describe('保留策略 — 过期判定', () => {
  it('未置顶条目在期限后被清理', () => { /* ... */ })
  it('置顶条目即使超过期限也不被清理', () => { /* ... */ })
})
```

- 每个用例自己建临时目录并在结束时清理；用例之间**不得**共享可变状态。

## 5. 手动验收清单

> 每个阶段按相关小节执行；Phase 7 需完整跑一遍。请在 [`../devlog/待办事项.md`](../devlog/待办事项.md) 勾选结果。

### 5.1 采集

- [ ] 记事本复制文字 → 800ms 内出现在列表顶部
- [ ] 浏览器复制富文本 → 以纯文本形式记录
- [ ] `Win+Shift+S` 截图 → 出现图片卡片，显示正确宽高
- [ ] 复制多行文本 → 换行结构保留
- [ ] 复制空白/清空剪贴板 → **不**产生新条目
- [ ] 反复复制同一段文字两次（间隔 > 5s）→ 不新增卡片，该卡片回到顶部

### 5.2 列表与操作

- [ ] 列表按时间降序，日期分组头正确（今天/昨天/日期）
- [ ] 置顶一条 → 出现粉色竖条与图钉；再点取消 → 恢复
- [ ] 删除一条 → 出现可撤销提示；点撤销 → 条目回来
- [ ] 清空历史 → 二次确认提示明确写「保留置顶」；确认后仅未置顶消失

### 5.3 搜索与筛选

- [ ] 输入中文关键词 → 即时过滤出正确条目
- [ ] 输入英文大小写混合 → 命中不区分大小写
- [ ] 切到「图片」→ 只剩图片卡片；切「文字」→ 只剩文字
- [ ] 搜索 + 筛选叠加 → 结果符合预期
- [ ] 无匹配结果 → 显示空状态提示，不白屏

### 5.4 期限与清理

- [ ] 设为 1 天 → 未置顶旧条目消失，置顶条目保留
- [ ] 设为 5 天 → 1 天前的条目重新可见范围符合预期
- [ ] 自定义非法值（如 0、9999、文字）→ 被拒绝或回退，界面不崩

### 5.5 复制与粘贴

- [ ] 点「复制」→ 到目标程序 Ctrl+V 得到正确内容（含图片）
- [ ] 点「粘贴」→ 内容落入切换后的前台窗口
- [ ] 自动粘贴后列表**不**新增条目（防自触发）
- [ ] 任务管理器等提权窗口点「粘贴」→ 明确提示需手动 Ctrl+V
- [ ] 设置改「仅复制」→ 主按钮变为复制并符合提示文案

### 5.6 生命周期与托盘

- [ ] 关闭窗口 → 进程仍在，托盘图标在，新增复制仍被记录
- [ ] 双击托盘 → 窗口重新出现，内容最新
- [ ] 托盘「暂停记录」→ 图标变灰，窗口显示暂停提示，复制不入库
- [ ] 托盘「退出」→ 进程真正结束
- [ ] 再次启动应用 → 唤起已有窗口，不产生第二个托盘图标
- [ ] 移动/调整窗口大小后重启 → 位置尺寸被记忆

### 5.7 隐私与安全

- [ ] 断网下所有功能可用（断网测试）
- [ ] 用资源监视器确认无对外网络连接
- [ ] 渲染层无法访问 `require`/`process`/文件系统（开发者工具验证）
- [ ] 查看 `main.log` → 不含剪贴板完整原文

### 5.8 打包

- [ ] 安装包可正常安装、启动、卸载
- [ ] 免安装 exe 在干净目录可运行
- [ ] 数据写在 `%APPDATA%\ClipHistory`，不在程序目录
