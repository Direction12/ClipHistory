# 历史粘贴（ClipHistory）

一个运行在 Windows 上的**本地剪贴板历史工具**：自动记录你复制的文字与图片，按时间降序展示，
支持置顶、删除、搜索、类型筛选，并可一键复制或**自动粘贴**回你原本的程序。

**数据全部存在本机，不联网、不上传。**

---

## 功能

- **自动记录**：后台每 800ms 检查剪贴板，文字与图片都会记录
- **按时间倒序的卡片列表**：带日期分组（今天 / 昨天 / 日期）
- **搜索与筛选**：关键词搜索（中文/英文皆可，大小写不敏感）+「全部 / 文字 / 图片」筛选
- **置顶**：置顶的记录**永久保留**，不参与自动清理
- **存储期限**：可选 1 / 3 / 5 天或自定义（1–365 天），到期自动清理未置顶记录
- **复制与粘贴**：卡片同时提供两个按钮 ——「复制」只写回剪贴板；「粘贴」写回后自动送到你原本的程序
- **托盘常驻**：关窗口不退出，记录不中断；托盘菜单可暂停记录、清空历史、退出
- **窗口置顶与透明度**：可让窗口始终显示在最前，并调整透明度（40%–100%）
- **键盘操作**：`↑`/`↓` 选择、「Enter 粘贴」、「Ctrl+C」复制、「Ctrl+F」搜索、「Esc」关闭
- **删除可撤销**：删除后提示条里会出现「撤销」按钮（**图片也一样**：撤销后缩略图立即恢复）

## 使用

双击 `ClipHistory.exe` 即可运行，无需安装。

- **关闭窗口**只是隐藏到托盘，程序继续在后台记录。要真正退出，请用**托盘菜单里的「退出」**。
- 数据位于 `%APPDATA%\ClipHistory`（可在设置面板里看到确切路径）。
- 想换个盘存放或彻底重置？退出程序后移动/删除该目录即可。

## 已知限制

| 限制 | 说明 |
|---|---|
| 提权窗口无法自动粘贴 | 以管理员权限运行的程序（任务管理器、UAC 提权程序）收不到模拟按键。此时会**明确提示你按 Ctrl+V**，不会静默失败 |
| 图片统一按 PNG 保存 | 剪贴板位图没有独立格式信息，占用可能略大 |
| 免安装目录体积约 368MB | Electron 运行时本身的体积，属正常量级 |
| 首次运行可能被 SmartScreen 拦一次 | 可执行文件未签名，属预期行为 |
| 删除**不进系统回收站** | 撤销窗口为 5 秒，超时、退出或崩溃后内容彻底删除、无法恢复。请把「撤销」当作唯一的反悔机会 |
